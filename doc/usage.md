# Ghost-Echo 操作マニュアル (usage.md)

<div align="center">
  <img src="../ghost-echo.jpg" alt="Ghost-Echo Header" width="100%">
</div>

Ghost-Echo は、X (Twitter) のリプライをステルスかつ効率的に収集するためのブラウザ拡張機能です。本ドキュメントでは、基本的な使い方からデータの管理方法までを解説します。

## 1. 導入方法

Ghost-Echo はプロトタイプ（v0.8以降）として、あらかじめビルドされたパッケージ版を利用できます。

1. **ZIPファイルのダウンロード**:
   GitHubリポジトリの [Releases](https://github.com/agenda23/Ghost-Echo/releases) ページにアクセスし、最新のリリース（または `v0.8` ）から `ghost-echo-extension.zip` ファイルをダウンロードします。
2. **ZIPファイルの展開（解凍）**:
   ダウンロードした ZIP ファイルをローカルの任意のフォルダに展開します。
3. **拡張機能画面を開く**:
   Chrome ブラウザでアドレスバーに `chrome://extensions/` と入力して開きます。
4. **デベロッパーモードを有効化**:
   画面右上の「デベロッパー モード」のスイッチを ON にします。
5. **拡張機能を読み込む**:
   「パッケージ化されていない拡張機能を読み込む」ボタンを押し、先ほど展開（解凍）したフォルダそのものを選択します。

## 2. データの収集方法

Ghost-Echo は、あなたのブラウザ操作をトリガーとして自動的に動作します。

1. **対象のスレッドを開く**:
   X にログインし、リプライを収集したいポストをクリックして詳細表示画面（スレッド画面）を開きます。
2. **ページをスクロールする**:
   通常通りマウスでページをスクロールします。
   - 拡張機能の動作が ON の場合、バックグラウンドで API 通信を読み取り、画面に表示されたリプライデータが自動的にキャプチャされます。

## 3. データの閲覧と管理

収集したデータは専用のダッシュボードで確認できます。

1. **ポップアップを開く**:
   ブラウザの拡張機能バーにある Ghost-Echo のアイコンをクリックします。
2. **ダッシュボードへ移動**:
   「ダッシュボードを開く」ボタンをクリックします。
3. **検索と表示**:
   - 上部の検索バーで、特定のキーワードやユーザー名（@handle）で絞り込みが可能です。
   - 「並び順」ボタンで、新しい順／古い順を切り替えられます。
   - 日時、ユーザー名、本文が一覧表示されます（よりシンプルにするためエンゲージメント情報は非表示化されています）。
4. **データのエクスポート**:
   - 「JSONエクスポート」または「CSVエクスポート」ボタンを押すと、現在表示・保存されているデータをダウンロードできます。
5. **データのクリア**:
   - 「全データクリア」ボタンでローカルに保存されたリプライデータをすべて消去できます。

## 4. デバッグと詳細設定

ポップアップ（拡張機能アイコンクリック時の画面）には以下の設定があります。
- **実行状態トグル**: キャプチャの ON / OFF を切り替えます。
- **デバッグモード**: ON にすると、開発者ツールのコンソールにAPIから取得した生の構造データ等が出力されるようになります（トラブルシューティング用）。

## 5. 手動でのビルドとパッケージ化（デベロッパー向けオプション）

ソースコードから手動でビルドし、配布可能なパッケージ（.zip）を作成する場合は、以下の手順を実行します。

1. **必要なツールのインストール**:
   Node.js (`npm` コマンド) と `zip` コマンドが使用できる環境が必要です。
2. **依存パッケージのインストールとビルド**:
   プロジェクトのルートディレクトリで以下のコマンドを実行します。
   ```bash
   npm install
   npm run build
   ```
3. **ZIPパッケージの作成**:
   生成された `dist` フォルダを以下のコマンドで圧縮します。
   ```bash
   zip -r ghost-echo-extension.zip dist/
   ```

## 6. 注意事項

- **ローカル動作**: 収集したデータはすべてあなたのブラウザ内（IndexedDB）にのみ保存され、外部サーバーへ送信されることはありません。
- **ステルス性**: 基本的にステルスで動作しますが、短時間での過度な高速スクロールは X のレート制限を誘発する恐れがあるため避けてください。
- **データのリセット**: IndexedDB を使用しているため、ブラウザのキャッシュを完全に削除したり拡張機能をアンインストールすると、収集したデータも消去されます。必要に応じてCSV等でバックアップ（エクスポート）してください。
