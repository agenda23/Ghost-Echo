# Ghost-Echo 操作マニュアル (usage.md)

Ghost-Echo は、X (Twitter) のリプライをステルスかつ効率的に収集するためのブラウザ拡張機能です。本ドキュメントでは、基本的な使い方からデータの管理方法までを解説します。

## 1. 導入方法 (開発モード)

現在はプロトタイプ段階のため、以下の手順でブラウザに直接読み込みます。

1. **ビルドの実行**:
   プロジェクトルートで以下のコマンドを実行します。
   ```bash
   npm install
   npm run build
   ```
2. **拡張機能画面を開く**:
   Chrome ブラウザで `chrome://extensions/` を開きます。
3. **デベロッパーモードを有効化**:
   右上の「デベロッパー モード」を ON にします。
4. **パッケージ化されていない拡張機能を読み込む**:
   「パッケージ化されていない拡張機能を読み込む」ボタンを押し、プロジェクト内の `dist` フォルダを選択します。

## 2. データの収集方法

Ghost-Echo は、あなたのブラウザ操作をトリガーとして自動的に動作します。

1. **対象のスレッドを開く**:
   X にログインし、リプライを収集したいポストをクリックして詳細表示画面（スレッド画面）を開きます。
2. **ページをスクロールする**:
   通常通りマウスでページをスクロールします。
   - **ステルスキャプチャ**: 通信プロトコルを直接監視し、APIレスポンスをキャプチャします。
   - **視認済みのみ保存**: 「実際に画面に 50% 以上表示されたツイート」のみが IndexedDB に記録されます。これにより、不自然な一括収集を避け、人間らしい挙動として記録されます。

## 3. データの閲覧と管理

収集したデータは専用のダッシュボードで確認できます。

1. **ポップアップを開く**:
   ブラウザの拡張機能バーにある Ghost-Echo のアイコンをクリックします。
2. **ダッシュボードへ移動**:
   「ダッシュボードを開く」ボタンをクリックします。
3. **検索と表示**:
   - 上部の検索バーで、特定のキーワードやユーザー名（@handle）で絞り込みが可能です。
   - 日時、ユーザー名、本文、エンゲージメント（いいね数・リプライ数）が一覧表示されます。
4. **データのエクスポート**:
   「JSONエクスポート」ボタンを押すと、現在保存されているすべてのリプライデータを JSON 形式でダウンロードできます。

## 4. 注意事項

- **ローカル動作**: 収集したデータはすべてあなたのブラウザ内（IndexedDB）にのみ保存され、外部サーバーへ送信されることはありません。
- **ステルス性**: 基本的にステルスで動作しますが、短時間での過度な高速スクロールは X のレート制限を誘発する恐れがあるため避けてください。
- **データのリセット**: IndexedDB を使用しているため、ブラウザのキャッシュを完全に削除したり拡張機能をアンインストールすると、収集したデータも消去されます。定期的なエクスポートを推奨します。
