# Ghost-Echo 開発計画 (development-plan.md)

Ghost-Echo は、Xのリプライ収集を自動化し、分析に役立てるためのツールです。本計画書では、現在のプロトタイプからプロダクト完成までのロードマップを示します。

## フェーズ 1: 基盤構築とプロトタイプ (完了)
現在のステータス。中心となるキャプチャ技術とデータ保存の確立。
- [x] Vite + CRXJS + TypeScript 環境の構築
- [x] `Fetch Hook` による API 通信のインターセプト
- [x] `IntersectionObserver` による視認判定（人間模倣ロジック）の実装
- [x] IndexedDB によるローカルデータ永続化
- [x] 基本的なダッシュボード UI と JSON エクスポート

## フェーズ 2: ステルス性と堅牢性の強化 (短期目標)
検知リスクをさらに抑え、より多くのデータを確実に取得するための改修。
- [ ] **人間模倣スクローラーの開発**:
  - `window.scrollTo` にランダムな速度・揺らぎ・一時停止を追加。
  - セッションごとにスクロールパターンを変化させる。
- [ ] **指紋（Fingerprinting）対策**:
  - Hook した `toString` などの関数の偽装。
  - プロキシ設定や User-Agent の柔軟な切り替えの検討。
- [ ] **APIパースの高度化**:
  - 画像・動画 URL の抽出。
  - リプライツリー（スレッド構造）の復元。
  - 引用ツイートの情報の取得。

## フェーズ 3: 分析機能と利便性の向上 (中期目標)
収集したデータを活用し、インサイトを得るための機能拡充。
- [ ] **ダッシュボードの分析ビュー**:
  - 投稿時間帯、バズっているユーザー、頻出キーワードのチャート表示。
- [ ] **詳細フィルタリング機能**:
  - インプレッション数、フォロワー数などによるフィルタの追加。
- [ ] **フォーマットの拡充**:
  - CSV / Excel エクスポートのサポート。
  - Google スプレッドシートへの直接同期機能（オプション）。

## フェーズ 4: 安定運用と配布準備 (長期目標)
多くのユーザーが安全に利用できる状態への整備。
- [ ] **自動ビルド・テスト環境 (CI/CD)**: GitHub Actions によるビルドの自動化。
- [ ] **ドキュメントの整備**: 開発者向け API 仕様書、貢献ガイドの充実。
- [ ] **UIの完全リデザイン**: よりモダンで使いやすいインターフェースへの刷新。

## 開発の優先順位
1. **ステルススクローラー**: 収集作業の自動化に不可欠。
2. **APIパース詳細化**: 構造化データの質を上げる。
3. **CSVエクスポート**: 非開発者ユーザーの利便性を最優先する。
