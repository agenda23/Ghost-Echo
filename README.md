# Ghost-Echo (Ghost-Echo)

X (Twitter) のリプライを収集・解析するためのブラウザ拡張機能です。
人間の行動を模倣するステルス技術（人間模倣アルゴリズム）を搭載し、検知を回避しながら効率的にデータを収集します。

## 主な機能
- **通信傍受 (Stealth Fetch Hooking)**: APIレスポンスを直接キャプチャし、正確なデータを取得。
- **人間模倣スクロール**: ランダムな揺らぎと停止時間を挿入し、Bot検知を回避。
- **視認ベースの取得**: `IntersectionObserver` を使用し、画面に表示された要素のみを処理。
- **自動重複排除**: 同一セッション内での重複データを自動的にフィルタリング。
- **データ管理 (Dashboard)**: 専用の管理画面で収集データの検索・フィルタリング・一覧表示が可能。
- **エクスポート**: データを JSON または CSV 形式でダウンロード（分析用）。
- **データ保存**: `IndexedDB` を使用した堅牢なローカル保存。

## セキュリティとプライバシー
- **完全ローカル動作**: 収集したデータが外部サーバーに送信されることはありません。すべての処理はブラウザ内で完結します。
- **匿名化エクスポート**: エクスポート時にユーザー名をハッシュ化するなどのプライバシー保護オプションを提供予定です。
